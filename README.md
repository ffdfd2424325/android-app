# Магазин сантехники (Plumbing Store)

Android приложение для интернет-магазина сантехники, разработанное с использованием современных технологий Android разработки.

## 📱 Описание

Приложение для покупки сантехнических товаров с функциональностью каталога товаров, корзины покупок, избранного и общей корзины. Приложение использует архитектуру MVVM и современные библиотеки Android.

## ✨ Основные возможности

- 🔐 **Авторизация** - Вход и регистрация пользователей
- 🏠 **Главный экран** - Навигация по основным разделам приложения
- 📦 **Каталог товаров** - Просмотр товаров с фильтрацией и поиском
- 🛒 **Корзина** - Управление товарами в корзине покупок
- ⭐ **Избранное** - Сохранение понравившихся товаров
- 👤 **Профиль** - Управление данными пользователя
- 🤝 **Общая корзина** - Совместное управление корзиной с другими пользователями

## 🛠 Технологии

### Основные технологии
- **Kotlin** - Язык программирования
- **Jetpack Compose** - Современный UI фреймворк
- **Android Architecture Components** - Компоненты архитектуры Android

### Библиотеки и зависимости
- **Room Database** - Локальная база данных для хранения товаров
- **Hilt** - Dependency Injection
- **Navigation Compose** - Навигация между экранами
- **Retrofit** - HTTP клиент для работы с API
- **Coroutines** - Асинхронное программирование
- **ViewModel** - Управление UI-связанными данными
- **LiveData/StateFlow** - Реактивные потоки данных

## 🚀 Установка и запуск

### Предварительные требования

1. Установите [Android Studio](https://developer.android.com/studio) (последняя версия)
2. Убедитесь, что установлен Android SDK с API уровня 24 и выше
3. Настройте эмулятор Android или подключите физическое устройство

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ffdfd2424325/android-app.git
cd android-app
```

2. Откройте проект в Android Studio:
   - File → Open → Выберите папку проекта
   - Android Studio автоматически синхронизирует Gradle файлы

3. Дождитесь завершения синхронизации Gradle (может занять несколько минут при первом запуске)

4. Запустите приложение:
   - Нажмите кнопку "Run" (▶️) или используйте сочетание клавиш `Shift + F10`
   - Выберите устройство (эмулятор или подключенное устройство)

### Установка APK файла

Если у вас есть готовый APK файл (`app-debug.apk`):

1. Включите "Установку из неизвестных источников" в настройках безопасности устройства
2. Скопируйте `app-debug.apk` на устройство
3. Откройте файл на устройстве и следуйте инструкциям установки

Или используйте ADB:
```bash
adb install app-debug.apk
```

## 🏗 Архитектура

Приложение следует архитектуре **MVVM (Model-View-ViewModel)**:

- **Model** - Модели данных и репозитории (`data/model/`, `data/repository/`)
- **View** - UI компоненты Compose (`ui/screens/`)
- **ViewModel** - Логика представления и управление состоянием (`ui/screens/*/ViewModel.kt`)

### Основные компоненты:

- **Room Database** - Локальное хранение товаров и корзины
- **Repository Pattern** - Абстракция доступа к данным
- **Dependency Injection (Hilt)** - Управление зависимостями
- **Navigation Compose** - Навигация между экранами
- **State Management** - Управление состоянием через ViewModel

## 📦 Модели данных

### Product
Модель товара с полями:
- `id` - Уникальный идентификатор
- `name` - Название товара
- `description` - Описание
- `price` - Цена
- `imageUrl` - Ссылка на изображение
- `category` - Категория
- `brand` - Производитель
- `stock` - Количество на складе
- `rating` - Рейтинг
- `isFavorite` - Флаг избранного

### CartItem
Элемент корзины с информацией о товаре и количестве.

### SharedCart
Общая корзина для совместного использования.
