# Android App Debug

Android приложение (debug версия).

## Описание

Это debug версия Android приложения в формате APK.

## Файлы

- `app-debug.apk` - Debug версия Android приложения

## Установка

Для установки APK файла на Android устройство:

1. Включите "Установку из неизвестных источников" в настройках безопасности устройства
2. Скопируйте `app-debug.apk` на устройство
3. Откройте файл на устройстве и следуйте инструкциям установки

Или используйте ADB:

```bash
adb install app-debug.apk
```

## Примечание

Это debug версия приложения. Для production используйте release версию с подписанным APK.
